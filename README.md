# DREAM HOUSE — Mobile App UI / Real Estate Edition

نسخة DREAM HOUSE المعاد تصميمها لتكون أقرب إلى شكل تطبيق موبايل احترافي وهادئ، مستوحاة من ترتيب التطبيق الظاهر في المرجع:

- واجهة Mobile-first نظيفة وخفيفة.
- أيقونات خطية بأسلوب iOS.
- ألوان أبيض / Navy / Teal مع لمسات ذهبية بسيطة.
- تسجيل دخول بشكل App وليس صفحة 3D.
- شريط تنقل سفلي واضح على الآيفون.
- بطاقات عقارات وإحصائيات مرتبة وواضحة.
- بيانات المكتب: **Engineer Ahmed Galal — 01035032020**.

## PDF العقارات المحددة

عند تحديد العقارات ثم اختيار **PDF واحد — كل المختار**:

- يتم إنشاء **ملف PDF واحد فقط**.
- كل صفحة تحتوي على **4 بطاقات عقارات: 2 جنب بعض × صفين**.
- كل بطاقة تشمل الصورة + السعر + العنوان + تفاصيل العقار + المالك + الهاتف + الملاحظات.
- الملف الواحد يمكن أن يحتوي حتى 20 عقارًا.
- هذا الأسلوب يتجنب صفحة PDF العملاقة غير العملية على الآيفون.

أما **صورة واحدة — كل المختار** فتنشئ صورة طويلة واحدة، وبنفس نظام **عمودين**: كل عقارين جنب بعض ثم الصف التالي.

## التشغيل

افتح `index.html` في المتصفح. البيانات والصور تُحفظ محليًا في المتصفح باستخدام LocalStorage + IndexedDB.
